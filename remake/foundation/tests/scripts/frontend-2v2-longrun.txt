# selection screen.

# tap the three-round gate has, plus round 3's own block replayed at +4864-tick periods (the

# is right; from round 4 the selection screen stops advancing on the replayed taps. The menu
# navigation is STATE-dependent (a fixed 5xJUMP + 6xDOWN + JUMP advances rounds 2 and 3 but
# not 4+), so a purely time-shifted script cannot drive an unbounded number of rematches. A
# true eight-round run needs per-round menu handling — a synthetic-pad change, not a script
# change — and that is a follow-up, not something to fake here.
#
# Five rounds is still more than the three-round gate and still exercises the thing the row
