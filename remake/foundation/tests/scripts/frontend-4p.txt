# P0 taps for the four-participant front-end run (issue #13).
#
# WHY a script: a headless run's only real device is the keyboard, which is controller 0
# (`--local-players` drives controllers 1..3 with its synthetic menu/battle patterns and never
# overrides a device). This walks P0's own panel through the selection flow, configures the
# stage page (60 s, 50 % health, 40 % balloons, so a headless round reaches the results in
# minutes instead of the 180 s default), advances stage -> VS -> battle and then fights.
# Frames are front-end logic ticks, one per capture frame.
#
# Timing on this build: the title scene is created at tick 0 and the selection scene at tick 34
# (the screen stack's fade), so P0's panel walk starts at 46. The stage page appears when one of
# the synthetic pads' confirms is accepted — the first one after every panel is back in its Team
# phase, measured at selection-frame 169 (tick 203) — so the stage taps below start at 230. The
# pads time themselves from the selection screen's own appearance, not from here.
#
# Screen-select grid (screen_select.cpp): `panel(c) = pos%3 + pos/3*2`; the cursor moves rows
# on left/right and columns on up/down, and the action column (pos%3 == 2) holds OK at pos 2.
# The stage page starts on row 0 and only its row 7 (START) begins the match; row 1 (stage
# variation) is skipped while stage == 0.
