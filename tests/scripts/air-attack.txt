# Issue #31 live recipe for the ordinary aerial slash.
#
# P1 is script-driven and P2 is deliberately idle, so it cannot interrupt the jump.
# --match starts directly in battle, but the first 60 simulation ticks are BattleStart.
# First, Jump at 110, make one Up tap at 118 (not a double tap), then attack at 121.
# This yields the ordinary Rena+0 slash, attackA/set 31, with a swing-start trace.
# After that swing and landing, a second Jump at 170 followed by Up at 178 and 180
# performs a real air dash; attack at 181 selects Rena+0's move-311 kick tag (set 40).
# Both attacks occur after the 60-tick BattleStart/countdown. Use the frame count to
# capture either pose: --frames=121 for the slash, --frames=181 for the kick.
# Attack-time Back versus target aim, including changed lock bearing and facing persistence,
# is separately asserted in simulation for Rena+0 and Akane+0.
#
# Capture an aerial pose after BattleStart:
#   SDL_AUDIO_DRIVER=dummy DAYBREAK_CAMINFO=1 DAYBREAK_DEBUG_KEYS=1 daybreak \
#     --install=<game-dir> --stage=data/stage03 --character=data/rena:0 \
#     --enemy=data/mion:0 --spawn=-1200,400,0 --spawn2=-1200,400,800 \
#     --match --script=tests/scripts/air-attack.txt \
#     --headless --out=/tmp/air-attack.ppm --size=640x360 --frames=181 --no-audio
