# Pipeline — how research artifacts flow

> Operational guide. Principles first, then the two pipelines
> (extraction + recomposition), data formats, and the offline command
> recipes. Condensed and translated from `docs/archive/PLANO.md` and
> `docs/archive/PLANO_RECOMP.md` (kept as historical reference).

## 0. Core principles

1. **`research/recomp/` is build output, not source.** It is always
   regenerated from `research/decompiled/` + `research/symbols/`.
   Hand-editing it is a process bug — edits get overwritten.
2. **`research/symbols/` is the only source of truth** for function
   identity (names, status, confidence) across the whole project —
   for `recomp/` and for any future Ghidra renames alike.
3. **Whatever can be deterministic must be deterministic.** AI decides
   only where there is genuine ambiguity (naming, conflict resolution).
4. **Annotate in Ghidra via tags/plate comments, never via
   `rename_function`** until a function is `locked`.

## 1. Directory roles

| Path | Role | Edit policy |
|---|---|---|
| `research/binary_data/` | Upstream evidence: per-function JSON store (`functions/`, keys `address/name/isThunk/isExternal/decompiled`), strings, types, callgraph, segments, phase reports (`scene_table/`, `network_analysis/`, `render_pipeline/`, `anti_analysis/`) | Reference; regenerated by extraction runs |
| `research/decompiled/` | Raw mass dump: one `.c` per function (`FUN_<addr>.c` + ~82 named + ~22 analysis files) | Read-only for the recomp pipeline |
| `research/recomp/` | Generated readable C (header schema + renames + clang-format) | **Never edit by hand** |
| `research/symbols/` | `functions.json` (name/status/confidence/hash), `types.json` (reconstructed structs), `notes.json` (ambiguities/TODOs) | Edit with care; human review for promotion |
| `research/progress/` | `coverage.json` (official metric), `last_ingest.json` | Generated; don't hand-edit |
| `research/tools/` | `ingest.py` → `generate_recomp.py` → `coverage_report.py` | Pipeline code |
| `research/extraction_phases/` | Raw phase dumps (`01_*`–`06_*`) + prioritization JSONs | Historical reference |

Name coverage: `binary_data/functions/` (3,087) ⊆ `decompiled/` (3,191;
adds named + analysis files). `recomp/` (3,169) = same corpus minus the
22 analysis files, plus 20 reviewed renames (which keep
`// Original: FUN_<addr>` headers), restyled to 4-space Allman.

## 2. Recomposition loop (the running pipeline)

```
research/decompiled/xyz.c ──┐
                            ├──▶ generate_recomp.py ──▶ research/recomp/xyz.c
research/symbols/*.json   ──┘
```

1. `python3 research/tools/ingest.py [--full]` — detects new/changed
   files in `decompiled/` via content hash, computes `signature_hash`,
   marks entries `stale` when the body changed.
2. Naming agents propose names (see §4) into `symbols/functions.json`
   as `suggested`, with ambiguities in `symbols/notes.json`.
3. Architect review promotes `suggested → reviewed → locked`
   (`depends_on_unresolved` non-empty blocks `locked`).
4. `python3 research/tools/generate_recomp.py` — regenerates `recomp/`
   (name substitution only for `reviewed`/`locked`; suggestions become
   comments; `clang-format --style=file` applied when available).
5. `python3 research/tools/coverage_report.py` — refreshes
   `research/progress/coverage.json`. **Run this before committing.**

All three scripts resolve paths from their own location
(`Path(__file__).parent.parent`), so the whole `research/` tree can
move as one — verified after the 2026-10-01 reorganization.

## 3. Extraction pipeline (Ghidra/MCP; mostly complete)

Phases 1–12 ran via Ghidra 11.x + GhidraMCP over a tunnel: recon →
function mapping (4,092) → prioritization (86 key) → decompile →
call-graph → hubs/dispatchers → Ghidra tags/plates → consolidated
report → mass decomp (3,087 `FUN_*`) → handoff to §2 → scene-table
analysis (phase 9: table hypothesis **disproved**, config struct found)
→ network analysis (phase 11/11b: DirectPlay 8) → anti-analysis sweep
(phase 12: clean). Raw outputs: `research/extraction_phases/`;
thematic reports: `research/binary_data/*/FASE*.md`.

Remaining MCP-dependent work is essentially done; what is left
(phases 10/11 follow-ups) is offline. The tunnel setup is archived in
`docs/archive/PLANO.md` §2/§10 and `docs/agents/extraction.md` — kept
for reproducibility, not current use.

## 4. Roles

| Step | Executor | Decision type |
|---|---|---|
| Detect new/changed dump files | deterministic script | mechanical, no AI |
| Suggest names/variables, flag ambiguities | local agent (batch) or extraction agent (Ghidra context) | high-volume analysis |
| Resolve conflicts, promote to reviewed | architect agent / human operator | global-scope decisions |
| Generate final `recomp/*.c` | deterministic script from `symbols/` | mechanical, reproducible |
| Validate (compiles? conventions?) | CI | automatic gate |

Two origins may suggest different names for one function — that is a
signal for the architect, not an error (`suggested_by` distinguishes
them; `symbols/notes.json` records disagreements; the operator decides).

## 5. Symbol lifecycle and schema

Status machine: `unreviewed → suggested → reviewed → locked`, with
`stale` reachable from `reviewed`/`locked` when `signature_hash`
changes. Minimal entry:

```json
{
  "FUN_00401230": {
    "suggested_name": "ParseAnimationHeader",
    "confidence": "medium",
    "status": "reviewed",
    "source_file": "research/decompiled/FUN_00401230.c",
    "signature_hash": "a1b2c3d4...",
    "depends_on_unresolved": [],
    "suggested_by": "agent:extraction",
    "reviewed_by": "marcelo"
  }
}
```

Notes (`type: ambiguity`, author, `resolved: false`) live in
`symbols/notes.json`. Full field reference: `docs/agents/local.md`.

## 6. Offline recipes

```bash
# Refresh everything after dump changes
python3 research/tools/ingest.py --full
python3 research/tools/generate_recomp.py
python3 research/tools/coverage_report.py

# Search strings / decompiled bodies / callers / callees
grep -r "pattern" research/binary_data/strings/
grep -l "pattern" research/decompiled/*.c
grep "FUN_<addr>" research/binary_data/callgraph/full_call_graph.txt
grep "^FUN_<addr>@" research/binary_data/callgraph/full_call_graph.txt

# Regenerate the repo index
python3 .github/scripts/generate_index.py
```
